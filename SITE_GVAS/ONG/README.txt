# GVAS — Site vitrine ONG

## Structure
- index.html
- style.css
- script.js
- assets/logo.png
- assets/ong-background.mp4  <-- à ajouter

## Ajouter la vidéo de fond
Placez votre vidéo MP4 dans :
assets/ong-background.mp4

La vidéo est configurée pour :
- autoplay
- muted
- loop
- playsinline
- couverture plein écran

## Personnalisation
Les couleurs principales sont définies au début de `style.css` :
--navy, --blue, --green, --lime

Vous pouvez modifier les textes, chiffres, liens et sections directement dans `index.html`.

Le site est responsive pour ordinateur, tablette et téléphone.
